# <p align="center"> 1.0.2.0 - July 17th, 2026 </p>

**Notes:**
- This release contains some important fixes, updates, as well as some cool new additions and replacements.
<br></br>

**Updating:**
- Please refer to [Updating Nuclear Sunset](<https://nuclearsunset.com/docs/main/updating>) for further instructions.
- Altered or outdated lists will not be supported.
- Notifications of missing mods post-update are normal and reflect plugin merging.
- For this update, you will need to manually update both xnvse and DXVK.
<br></br>

**Updating xnvse:**
- In MO2, on the right pane, click the Downloads tab
- At the bottom of the pane, type "xnvse" and find version 6-2-8
- Right click the download and click "Open" 
- Extract the contents of this archive **EXCLUDING THE DATA FOLDER** to your Stock New Vegas Folder
<br></br>

**Updating DXVK:**
- Follow the same steps as listed above for xnvse, except searching for DXVK 3.0.1
- Extract entire contents of the archive to your Stock New Vegas Folder
- This will require you to rerun the "Configure Game Settings" option in MO2
<br></br>
